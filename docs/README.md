# Documents

| File | What it is |
| --- | --- |
| [`screenshots/`](screenshots/) | The screenshots used in the main README, drawn from the real app with made-up entries. See [Screenshots](../README.md#screenshots) for how to draw them again. |
| [`privacy.md`](privacy.md) | The privacy policy. It is a draft: the contact details are placeholders until the owner approves it. |
| [`fdroid/`](fdroid/) | The F-Droid build recipe (`com.persmon.akatabo.yml`) and the checklist for a first submission (`READINESS.md`). |
| [`BUGS.md`](BUGS.md) | Known bugs that are small enough to leave for now, with how to trigger each one and a suggested fix, and the ones fixed since. |
| [`HANDOFF.md`](HANDOFF.md) | Notes for whoever picks the work up next: where things stand and what is left. |

The project's main notes are at the repository root: [`CHANGELOG.md`](../CHANGELOG.md), [`PRODUCT.md`](../PRODUCT.md), [`PLAN.md`](../PLAN.md), [`PROGRESS.md`](../PROGRESS.md) and [`SHIP_GATE.md`](../SHIP_GATE.md). To help, start with [`CONTRIBUTING.md`](../CONTRIBUTING.md).
